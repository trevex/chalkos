# chalkctl gen

Generate files of a cluster

## Synopsis

Generates the files a cluster starts from. Its command needs no secrets file or client file.

## Examples

```
  chalkctl gen secrets --plaintext
```

## Options

```
  -h, --help   help for gen
```
