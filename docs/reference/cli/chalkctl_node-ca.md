# chalkctl node-ca

Manage the node CA

## Synopsis

Manages the node CA, which issues the certificates nodes serve. Its command needs the secrets
file.

## Examples

```
  chalkctl node-ca rotate
```

## Options

```
  -h, --help   help for node-ca
```
