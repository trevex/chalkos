# Command line

chalkos has two command line tools. Their pages are generated from their help.

- [chalkctl](chalkctl.md): Build, sign, install and operate chalkos clusters
- [chalklab](chalklab.md): Run a chalkos cluster's nodes as QEMU virtual machines on this machine

Every command shows its description, examples and flags with `--help`, and `completion` writes a shell completion script.
