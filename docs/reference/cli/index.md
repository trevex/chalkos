# Command line

chalkos has three command line tools: chalkctl and chalklab run on an operator's machine, chalkcfg on a node. Their pages are generated from their help.

- [chalkctl](chalkctl.md): Build, sign, install and operate chalkos clusters
- [chalklab](chalklab.md): Run a chalkos cluster's nodes as QEMU virtual machines on this machine
- [chalkcfg](chalkcfg.md): Print the config documents of the node chalkcfg runs on

Every command shows its description, examples and flags with `--help`. chalkctl's and chalklab's `completion` writes a shell completion script.
